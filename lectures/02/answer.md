## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：学習率 `lr` を 2e-4 → 2e-3（10 倍）に変更。他の設定は同じ。結果は `result_2e-3.json`、`eval_after_2e-3.json`
- 結果（比較表や数字）：

  | | lr = 2e-4 | lr = 2e-3 |
  |---|---|---|
  | format_rate（学習後） | 1.0（21/21） | 1.0（21/21） |
  | content_rate（学習後） | 0.905（19/21） | 0.810（17/21） |
  | 根拠あり 15 問の正解 | 15/15 | 14/15 |
  | 根拠なし 6 問の正解 | 4/6 | 3/6 |
  | 退行 | なし | なし |
  | セクション 6 の asserted | 2/4 | 3/4 |
  | 最終 loss（step 40） | 0.01〜0.02（ノートブック記載の目安。自分の実行値は記録し損ねた） | 0.012（step 10: 0.912 → 20: 0.078 → 30: 0.016） |
  | 学習時間 | 240〜290 秒（同上） | 229 秒 |

  - 2e-3 は loss が早く下がった（step 10 で 0.91。目安は 1.5 前後）が、最終 loss は同程度だった。それでも content_rate は下がった。Training Loss が低いことは、学習に使っていない質問への判断が良いことを意味しない

  - 学習前の出力は 2 回の実行で 21 問とも一致した（比較の条件は揃っている）
  - 2e-3 で新たに落ちた質問：「PDF 以外でも出せますか」（根拠ありに確認要求で逃げた）、「課題の文字数に制限はありますか」（提出期限の文で断定）
  - セクション 6 の「次回の講義のテーマ」が needs_review → asserted（提出期限の文）に変わった
  - 2e-3 では FAQ に無い質問 4 つに同じ「提出期限」の文を返した
  - 考察：
    - 学習率を 10 倍にしても形式は崩れなかったが、根拠の有無の判断は悪化した。理由は学習データが十分にあり、過学習の可能性はあれど学習不足にはならないからと考える。
    - 最終 loss は同程度だったのに test の結果は悪化した。loss だけでは評価指標としては不十分であり実際に出力を確認することが重要だと分かる。
    - 2e-4 でも断定は残っており、学習率の調整では改善しないと考えられる。

- ファインチューニングが向く場面・向かない場面についての考察：
  - 向く：〔形式・口調のように、学習データ全体で共通する振る舞い〕。理由：〔今回の結果〕
  - 向かない：〔FAQ に根拠があるかの判断や、FAQ の事実そのもの〕。理由：〔今回の結果〕と、〔FAQ が変わったら？〕
